\# Password Strength Analyzer



\## Project Overview

This is a beginner-level Python project that checks password strength and provides basic suggestions to improve password security.



\## Features

\- Identifies empty passwords

\- Detects selected common passwords

\- Checks password length

\- Checks lowercase and uppercase letters

\- Checks numbers and special characters

\- Displays password strength as Weak, Medium, or Strong

\- Provides basic improvement suggestions



\## Technologies Used

\- Python

\- Python unittest



\## How to Run

1\. Install Python.

2\. Open Command Prompt in the project folder.

3\. Run the application:



&#x20;  `py main.py`



4\. Enter a test password when prompted.



\## Run Automated Tests

Run this command:



`py -m unittest -v test\_password`



\## Project Files

\- `main.py` — Password analysis logic

\- `test\_password.py` — Automated tests

\- `README.md` — Project documentation



\## Important Note

This project uses a basic password-strength heuristic for educational purposes. It does not guarantee that a password is secure and is not a substitute for a professional password-security assessment.
